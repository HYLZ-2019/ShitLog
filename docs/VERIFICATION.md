## 设备验证阻碍

本次创建的无窗口 API 35 模拟器在冷启动后出现系统服务崩溃和“进程 system 没有响应”。诊断截图仅保存在本机，未纳入公开仓库。应用启动停留在系统启动画面，完整 UI 测试返回 Process crashed，定向数据库设备测试又遇到系统 Binder 的 DeadObjectException。因此以下项目不能宣称已通过：

- 真机／模拟器上的开始、结束、表单保存完整流程。
- 页面重建、锁屏、进程终止和设备重启后的实际恢复。
- Android 文件选择器中的实际导出／恢复操作。
- 深色主题、字体放大和所有页面的视觉验收。
- 厂商系统云备份与设备转移行为。

模拟器是本次实验单独创建的实例，已在异常后关闭。测试环境异常不等于应用通过或失败，需在可用的设备上重新验证。
